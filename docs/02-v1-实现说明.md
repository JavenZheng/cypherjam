# 02 · CypherJam v1 实现说明

2026-11-07 · 单机版（无账号、无联机、无手机适配）

## 1. 入口与依赖

- 唯一入口：`app/index.html`，双击即可打开（`file://` 也能出声）。
- 声音引擎：**Tone.js 15.1.22**，MIT 许可。已下载到 `app/vendor/Tone.js`（约 345 KB，UMD 构建），页面用 `<script src="vendor/Tone.js">` 本地加载，不依赖网络，也不受 CDN 屏蔽影响。
- 来源：`https://unpkg.com/tone@15.1.22/build/Tone.js`。
- 没有构建步骤、没有 npm 依赖。改完刷新页面即可。

## 2. 速度与调性

- **BPM = 127**。用户给的是 126，但公开曲库页面（Shazam、Digital Music Pool、Mixgraph）对 FISHER & Aatig《Take It Off》均标 **127 BPM**，因此按「以核实为准」采用 127。若之后确认是 126，只需改 `app/index.html` 里的 `const BPM = 127`。
- 该曲公开资料标 **E♭ minor**；产品约束要求锁 **A 小调**，所以本版不跟随参考曲调性，只借它的音色与律动方向。
- 16 分音符 `STEP = 60/127/4 ≈ 0.118s`，1 小节 ≈ 1.890s。

## 3. 音频架构

信号链（实时与离线渲染共用同一套 `buildEngine`）：

```
drums ─────────────────────────────┐
bass / stab / atmos / sample → duckGain ─┴→ mixBus
mixBus → userFilter → buildFilter → masterGain → slamGain → Limiter → 输出
                          ├→ reverbSend → Convolver ─┐
                          └→ delaySend  → FeedbackDelay ─┴→ masterGain
```

- **侧链（sidechain）**：没有用 Compressor。Tone.js 没有真正的 sidechain 输入，靠压缩器模拟会不稳定，也不好离线复现。实际做法是：kick 每次触发时对一个 `duckGain` 做包络——先 `cancelScheduledValues`，5 ms 内线性降到 `1 - 0.72 × sidechain/100`，再用 300 ms 指数回到 1。默认 sidechain 55 → 最低约 0.60。被压的是 **bass / stab / atmos / sample**，鼓组不压。这样离线渲染与原演奏一致，可重复。
- **低频管理**：bass 先过 `60 Hz` 高通（-24 dB/oct）再进混音，避免与 kick 抢 60 Hz 以下；kick 是 `MembraneSynth` 的 C2（约 65 Hz），本身较短（decay 0.26），再由侧链把 bass 让开。
- **滤波器**：`userFilter` 是表演用的全局低通（滑块 0–100 映射 60 Hz–18 kHz，对数）；`buildFilter` 是 build 专用的下扫滤波器，二者串联，互不干扰。
- **混响**：`Tone.Convolver` + 程序生成的脉冲响应（噪声 × 指数衰减 × 轻低通）。**没有用 `Tone.Freeverb`**：它基于 AudioWorklet，`file://` 直接打开时模块加载失败，会让混响整个哑掉。IR 在页面加载时生成一次，实时与离线渲染共用同一个 `AudioBuffer`。
- **延迟**：`FeedbackDelay('8n', 0.34)`，发送量由滑块控制。

## 4. 默认 pattern：故意留白

产品哲学是「让用户自己往里加」，所以默认不填满四轨。

| Pattern | 默认内容 |
|---|---|
| A GROOVE | kick 0/4/8/12；反拍 hat 2/6/10/14。其余全空。 |
| B HOOK | A 的鼓组 + 钩子音型在 3/7/11/15（E5、C5、G5、D5）。 |
| C BREAK | kick 0/8；反拍 hat；第 0 步一个 Am 氛围铺底。 |
| D PEAK | 四拍 kick、clap 4/12、hat 正反拍、bass A2 在 2/6/10/14、钩子 3/7/11/15。 |

- 切 pattern 不打断 Transport：运行中点击只记 `pending`，在 `onStep` 里检测到 `step === 0`（小节线）才真正换，换完立刻继续。
- 格子点击：鼓组 0 → 1（轻）→ 2（重）→ 0；旋律/氛围格是开关。STAB 轨有 `HOOK / CHORD` 两种插入模式。

## 5. 钩子音色

- 占位钩子由 **FMSynth** 合成：`harmonicity 2.5`、`modulationIndex 9`、包络 decay `0.065s`，再过一个 `850 Hz / Q5` 带通。听感是短促、带共鸣峰、可反复播放的打击型音色，接近「人声切片」的角色，但**不是**任何商业人声采样。
- 所有声音都由代码合成，项目里没有任何第三方采样或音效。
- `USE AS HOOK: ON` 可以把用户导入的采样接到钩子位：STAB 轨里 `kind: 'hook'` 的事件会改播采样，而不是合成器。这样「用现实声音替换钩子」这条路径已经打通。

## 6. 用户音频导入（本版只做导入，不做麦克风）

流程：`decode → 混单声道 → 裁起音 → 归一化 → 测基频 → 最近 A 小调音级`

- 支持 WAV / MP3，拖入或选择文件；解码用浏览器原生 `decodeAudioData`。
- 最长取 **8 秒**，超出截断。
- **裁起音**：以整段峰值的 6% 为阈值，连续 3 个样本超过才算起音，回退 5 ms 作为裁切点。
- **归一化**：裁切后峰值归一到 0.94。
- **测基频**：在最响的 4096 样本窗口做归一化自相关，范围 55–1000 Hz，置信度低于 0.55 视为测不到。
- **调性吸附**：把基频换成 MIDI 浮点，找最近的 A 小调音级（A/B/C/D/E/F/G），用 `playbackRate = 2^(偏差/12)` 移调；偏差小于 0.02 半音视为本来就在调内。
- **测不到基频就明说**：元数据标「未自動調音（測不到穩定基頻）」，不会假装调过。
- **网格对齐**：不做时间伸缩。采样是 one-shot，从被触发的那一步开始播放，因此起点永远对齐网格；长度不随 BPM 拉伸。这是本版的明确取舍。
- 采样挂在额外的 **SAMPLE** 轨（第 7 行），可以单独 mute/solo，也可以 `USE AS HOOK` 顶替钩子位。

## 7. 过渡手法

- **BUILD / RISER（2 小节）**：下一小节开始，`buildFilter` 从 18 kHz 指数下扫到 220 Hz，同时白噪声 riser 从 300 Hz 扫到 3800 Hz、音量渐强；2 小节后滤波器瞬间打开，`impact` + 专用 `boom` 重击并触发侧链。
- **SLAM**：下一拍开始，`slamGain` 在 2 ms 内降到 0，静音一个八分音符（2 个 16 分步，约 0.236s），然后恢复并重击。
- 实现注意：build 的释放点、slam 的重击都**不提前**在同一个合成器上排未来事件。Tone 的包络时间线要求事件时间递增，提前排程会让后续常规 kick 抛 `time must be greater than or equal to the last scheduled time`。现在 build 释放和 slam 重击都通过 `Transport.scheduleOnce` 在到点时触发；离线渲染则把过渡展开成按时间排序的点事件。

## 8. 录音与导出

- 现场演奏时记录日志：每一步（16 分）的事件、该步的参数状态（filter / reverb / delay / sidechain / mute / solo）、过渡指令。
- 停止后（或到达选定小节数）用 `Tone.Offline` 建一个全新离线上下文，按绝对时间重放整段日志，再编码为 **16-bit PCM WAV**（双声道，采样率跟随当前上下文）。导出前把峰值归一到约 0.92，避免每条文件响度差太多。
- 离线渲染尾部多留 2 秒，容纳混响与延迟尾巴。
- 失败时退回 `MediaRecorder` 抓实时输出（WebM/Opus），界面上会说明「品質較差、需保持播放」。
- 已知边界：录制开始前就已经在跑的过渡不会进日志；录制结束前 2 秒内才触发的 build 释放可能被尾部截断。

## 9. 键盘

| 键 | 作用 |
|---|---|
| `Space` | 播放 / 停止（不会误触当前聚焦的按钮） |
| `1` `2` `3` `4` | 切 A / B / C / D（落在小节线） |
| `B` | build / riser |
| `S` | slam |
| `Z` `X` `C` `V` `N` | 分别 mute drums / bass / stab / atmos / sample |
| `R` | 复位 pattern 与参数（保留已导入的采样） |

鼠标只作辅助：格子编辑、滑块、M/S、pads、导入、录音。

## 10. 素材来源与授权

- 项目**未打包任何**第三方采样、loop 或音效。
- 鼓、bass、stab、pad、hook、impact、riser 均为 Tone.js 合成器实时合成。
- 混响 IR 由页面内 `Math.random()` 生成噪声再乘指数衰减，不来自任何录音。
- Tone.js 为 MIT 许可。
- 用户导入的文件只在本机内存中处理，不上传；其来源与授权由用户负责。本版明确不使用 CC-BY-NC 或授权不明的素材。
- **商用提示**：把地铁报站、商场广播等公共广播内容录下来用于商业活动，可能涉及额外限制；私人派对使用风险较低。这是提示，不是阻止。

## 11. 实测记录

无头 Chromium（Playwright，chromium headless shell 1228）实测通过：

- `file://` 直接打开无控制台 / 页面错误；点击 ENTER 后 Transport 进入 `started`，步进持续推进。
- 键盘 `2` 切 B：先进入 pending，跨过小节线后 `playing` 变为 B，播放未中断。
- 键盘 `x` mute bass 生效，再按恢复。
- build + slam 连续触发，修复调度顺序后无报错。
- 离线渲染 2 小节：时长 3.89s（含 2s 尾巴）、双声道、峰值 0.278。
- 导入 220 Hz 正弦（前置 0.2s 静音）：裁掉约 195ms、归一化 94%、识别为 A3 且在调内。
- 导入 233 Hz：识别为 B3，自动 +1.0 半音调到 A 小调；导入白噪声：正确标为「未自動調音」。
- 只留 SAMPLE 轨、静音其余组，离线渲染仍有声（峰值 0.278）。
- 端到端录音：录约 4.6s（含一次 build）→ 离线渲染 → 下载 1.1 MB WAV；较短一次为 790 KB。
- `R` 复位后 filter 100 / reverb 15 / delay 8 / sidechain 55，mute/solo 清空，播放继续。
- 点击格子后按 Space，只切换一次播放，没有被按钮的默认行为吃掉。

**未验证**（需要你在真机 / 耳机上判断）：

- 音色与混音平衡、侧链「呼吸感」是否够、build/slam 的听感冲击。
- 真实 Chrome / Safari 图形界面下的表现（测试用的是无头 Chromium）。
- 20 分钟连续演奏是否会出现漂移、内存增长或爆音（本版没有做长时压力测试）。
- 系统拖拽导入（测试用进程内合成 WAV 走同一处理函数）、MP3 解码、下载的 WAV 在 DAW 里的回放。
- 麦克风录制（下一轮）。

## 12. 已知限制

- pattern、参数、导入的采样都只在内存里，刷新即丢失（没有做持久化）。
- 没有逐步撤销，只有一键复位。
- 采样单声道、上限 8 秒、不做时间伸缩。
- 自动调音是启发式：只按基频判断，噪声、打击乐、复音人声可能测不到或测偏；测不到会明示。
- 手机、多人、账号、云同步、AI 生成均不在本版。
