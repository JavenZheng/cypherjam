## 1. 诊断：「按下只会出现一个带 A 的方块」

### 1.1 实测复现

用 Playwright 无头 Chromium 在真实页面上定位（不是静态猜测）：

```
点击 BASS 行第 1 格（空）之后：
  text  = "A"
  title = null                     // 没有任何 hover 提示
  class = "cell on"
  aria  = "BASS step 1"
```

对应代码路径：

- 网格每格是 `<button class="cell">`，空网格**没有文字、没有 title、没有占位符**，只靠 `.cell.on` 的底色区分「有 / 无」。
- 点击走 `toggleCell()` → `insertEvent('bass')`，而 v1 的 `insertEvent` **写死返回 `bassEvt('A2')`**，用户没有选音高的入口。
- 渲染时 `tagFor()` 对 bass 做了 `v.note.replace(/\d/g,'')`，把 `A2` 削成 `A`。
- ATMOS 的 `air` 事件在 `tagFor()` 里也返回 `'A'`，所以两个不同的轨道都会产出「带字母 A 的方块」。
- 唯一说明是一行 10px 的「點格子編輯」，位置在 STAB INSERT 行的最右侧，和网格没有视觉关联。

### 1.2 结论：这不是「用户不会用」，是三个可发现性缺陷叠加

1. **看不出空格能点**：空格是暗色、无字、无边框强调、无 hover 提示的按钮。
2. **看不出点下去会发生什么**：没有 `title`，没有占位文字；点完才知道生成了一个音。
3. **无法理解生成的内容**：`A2` 被削成 `A`，既不是音名（缺八度），也不是可读的词；加上 ATMOS 也显示 `A`，用户无法建立「方块文字 = 音高」的心智模型。

### 1.3 修复（本次已落地）

| 缺陷 | 修法 |
| --- | --- |
| 空格不可见 | 所有空格子显示淡色 `+`（`.cell.ghost`），hover 变绿；空鼓格同样有 `+` |
| 没有提示 | 每格都写 `title`：说明「现在是什么 / 点下去会怎样」，例如 `BASS · STEP 3 — 空 · 點擊＝新增 A2（可改右上 NOTE）` |
| 音高不可读 | bass 直接显示完整音高 `A2`；atmos 显示 `AIR / PAD`，sample 显示 `●` |
| 不能选音高 | 网格上方新增 **NOTE** 下拉（A2–A4，全部在 A 小调内）；BASS 与 HOOK 插入都用它 |
| 轨道含义不明 | 每行标签加副标题：`BASS · A2`、`STAB · HOOK/CHORD`、`ATMOS · AIR`、`SAMPLE · 1-SHOT`，随插入设置实时更新 |
| 说明太弱 | 网格上方改成整条提示栏，明确写「點格子就能編輯 / 空格按一下新增、再按一下刪除 / 鼓是輕→重→關」 |

复测（同一无头环境）：空格 `textContent === "+"`，`title` 非空；点 BASS 空格后格子显示 `A2`；`NOTE` 选 `C3` 后点格显示 `C3`。

## 2. 新手教程

### 2.1 入口与首次策略

- 顶栏右上角常驻 **TUTORIAL · 教學** 按钮（琥珀色描边 + 柔光，是顶栏唯一暖色按钮）。
- 第一次进入（`localStorage` 无 `seen` 标记）自动弹出教程，**只走 3 步**：讓聲音出來 → 在網格上畫一個音符 → 換一個 pattern。走完即关闭并写 `seen`。
- 之后再点 TUTORIAL 打开**课程菜单**，8 个动作全列，已学过的打 ✓，用户自己挑一项开始；从选中那项起会顺序往下走，也可随时关闭。
- `localStorage` key：`cypherjam.tutorial.v2`（`file://` 下不可写时静默降级，不阻断使用）。

### 2.2 八个步骤与检测条件

每步都必须检测到**真实操作**才标记完成，不是读文字点「下一步」。

| # | 步骤 | 用户要做的动作 | 检测钩子 |
| --- | --- | --- | --- |
| 1 | 讓聲音出來 | 停掉播放再开回来 | `togglePlayback()` → `tutEvent('play')` |
| 2 | 在網格上畫一個音符 | 在 BASS 行点一格空格 | `toggleCell()` → `tutEvent('note', {lane:'bass', created:true})` |
| 3 | 換一個 pattern | 按 `2` 或点 `B` | `selectPattern()` → `tutEvent('pattern')` |
| 4 | 換音色 | 切 HOOK / CHORD，或汇入音档 | 插入模式点击 / NOTE 变更 / `processBuffer` 成功 |
| 5 | 改音量與濾波 | 拖动 FILTER | `filter` 滑桿 `input` → `tutEvent('slider',{id:'filter'})` |
| 6 | 靜音單軌 | 按 `X` 或点 BASS 的 M | `muteGroup()` / `toggleMS()` → `tutEvent('mute',{group:'bass'})` |
| 7 | BUILD / SLAM | 按 `B` 或 `S` | `scheduleBuild()` / `scheduleSlam()` |
| 8 | 錄自己的聲音 | 汇入 WAV / MP3 | `processBuffer()` 成功 → `tutEvent('sample')` |

防误判：第 2 步只认 **bass 轨且是新增**；第 5 步只认 **FILTER**；第 6 步只认 **bass 组**。做错轨时不在菜单里跳步，而是在「現在請你做一次」下面提示正确位置，例如「BASS 那一行，點一格空格」。

### 2.3 交互细节

- 完成瞬间：提示区变绿 `✓ 已完成：…`，1 秒后自动进入下一步；「下一步」按钮在校验通过前置灰不可点。
- **跳過**：永远可点，直接进下一步（最后一步为「结束」），不做硬墙。
- 目标控件有琥珀色脉冲描边（`.tut-focus`），随步骤切换。
- 未播放就按 `B` / `S`：不会静默失败，提示区改为「先按 Space 開始播放」。
- 浮层是左下角浮动卡片（宽 372px），不是全屏遮罩，网格与控制始终可点。

### 2.4 键盘不受影响（硬性要求）

- `keydown` 仍绑定在 `window`，教程只加 DOM，不注册拦截层，也不 `stopPropagation` 之外的任何监听。
- 教程内的按钮不接收 `Space` 的默认激活：`onKeyDown` 对受管按键统一 `preventDefault()`，所以焦点停在「跳過」上按 Space 仍是播放/停止，不会误触按钮。
- 实测（见第 5 节）：教程打开、焦点在教程按钮上时，`Space` 仍能起停，`3` 仍能切 pattern。

## 3. Pattern 库扩充

### 3.1 结构

风格包定义在 `STYLES`：每个包带自己的 BPM、swing、pattern 字母表与名字。
切换风格时：先 `setTempo()`（更新 `BPM / STEP / BAR` 与 `transport.bpm`、`transport.swing`），再取该风格的 pattern 缓存；UI 的 1–8 按钮与键盘 `1–8` 自动重建。

- 每个风格的编辑互相独立（`styleCache`），切走再切回不丢改动。
- 切换风格会回到 `A`，避免旧字母在新包里不存在。
- 录音日志记录 `stepSec`，因此换风格后离线渲染仍按录制时的 BPM 重放。

### 3.2 TECH HOUSE（127 BPM，沿用）

BPM 依据不变：参考曲 FISHER & Aatig《Take It Off》公开资料标 127（非 126），v1 已核实并写入 `docs/02`。

新增 4 组，加上 v1 的 A–D，共 **8 组可切换 pattern**（键盘 `1–8`）：

| 字母 | 名字 | 鼓组形态 | 和声 / 低频 | 用途 |
| --- | --- | --- | --- | --- |
| A | GROOVE | 四拍 kick + 反拍 hat，无 clap | 无 | 默认底，刻意留白 |
| B | HOOK | 同 A | 4 个 Hook 切片（E5/C5/G5/D5） | 钩子段 |
| C | BREAK | 半速 kick（0/8）+ 反拍 hat | Am 三音长垫 | 换气 |
| D | PEAK | 四拍 kick + clap(4/12) + 16 分 hat | 反拍 bass A2 + 4 个 Hook | 高潮 |
| **E** | **ROLL** | 四拍 kick + clap(4/12)，**16 分 hat 连打**（每 4 步一个重音） | 纯反拍 bass A2，短音 | 推段落的「卷」 |
| **F** | **CHOP** | **切碎 kick（0/3/8/11）**，clap(4/12)，反拍 hat | **两音交替 bass：A2 / C3 / A2 / E3** | 更「断」的律动 |
| **G** | **DUB** | **半速 kick（0/8）**，反拍 hat，无 clap | 稀薄长 bass（0/10）+ 四音 pad（A2 E3 C4 G4） | 现场换气、留空间 |
| **H** | **TOOL** | 四拍 kick + clap(12) + 反拍 hat | 无 | 纯工具鼓，可叠在任何段前 |

### 3.3 DEEP HOUSE（122 BPM）

**BPM 说明（诚实标注）**：参考曲是 tech house，没有 deep house 的直接参照，122 是 deep house 常见区间（约 118–124）内的设计选择，**不是**从参考曲核实得到的值；如需与某首具体曲目对齐，应再单独核实。

| 字母 | 名字 | 鼓组形态 | 和声 / 低频 |
| --- | --- | --- | --- |
| A | WARM | 四拍 kick + 反拍 hat，无 clap | 4 次反拍 bass（A2）+ **Am7 长垫** |
| B | SUNSET | 四拍 kick + clap(4/12) + 反拍 hat | bass A2 / C3；**Fmaj7 → Am7** 两个 offbeat 和弦 |
| C | DUB | 半速 kick（0/8）+ 反拍 hat | Am7 长垫 + 单点低音，速度感交给 hat |
| D | BREAK | 半速 kick，**无 4/4 推进感** | **Cmaj7 长垫**，整轨无 bass |
| E | PEAK | 四拍 kick + clap + 16 分 hat | 反拍 bass + **Am7 / Dm7** stab |
| F | OUT | 只剩 kick + 反拍 hat | 无 |

与 Tech House 的差异：BPM 慢 5、hat 不做 16 分连打、低频更稀、和声比重上升（pad / 七和弦为主），整体更宽更「躺」。

### 3.4 JAZZ HOUSE（124 BPM，16 分 swing）

- **Swing**：`transport.swing = 0.35`，`transport.swingSubdivision = '16n'`。Offbeat 的 16 分音符被推后约 35%，听感是「拖」。因为调度全部基于 `Transport` 的 `'16n'` 事件，swing 直接作用在步进上，不需要改 pattern 数据。
- **BPM 说明**：124 同样是设计选择（jazz house / 带 swing 的 house 常见 120–126），与参考曲无关。

**锁 A 小调下的七 / 九和弦做法**：只从 A 自然小调音级 `{A, B, C, D, E, F, G}` 里取和弦音，因此不会出现 C# / G#，也就不可能离调。

| 和弦 | 音 | 音级检查 |
| --- | --- | --- |
| Am7 | A3 C4 E4 G4 | A C E G ✓ |
| Dm7 | D4 F4 A4 C5 | D F A C ✓ |
| Dm9 | D4 F4 A4 C5 E5 | D F A C E ✓ |
| Fmaj7 | F3 A3 C4 E4 | F A C E ✓ |
| Em7 | E4 G4 B4 D5 | E G B D ✓ |
| G7 | G3 B3 D4 F4 | G B D F ✓ |
| Cmaj7 | C4 E4 G4 B4 | C E G B ✓ |

| 字母 | 名字 | 鼓组形态 | 和声 / 低频 |
| --- | --- | --- | --- |
| A | LATE NIGHT | 四拍 kick + 反拍 hat，无 clap | walking bass（A2 C3 E3 G2，四分） + **Am7 / Fmaj7** offbeat + Am7 长垫 |
| B | SEVENTH | 四拍 kick + clap(4/12) + 反拍 hat | walking bass（A2 C3 F3 E3） + **G7 → Am7**（7/15 步） |
| C | NINTH | 四拍 kick + 反拍 hat | bass A2 / G2 + **Dm9 / Cmaj7** + Am7 长垫 |
| D | SWING PEAK | **切碎 kick（0/3/8/11）** + clap + 16 分 hat | walking bass + **Am7 / Em7** |
| E | SOLO | 四拍 kick + 反拍 hat | 只有 walking bass（A2 C3 E3 A3），留白给现场 |
| F | OUT | 四拍 kick + 反拍 hat | **Fmaj7 长垫**，收尾 |

swing 在离线渲染里是否生效：`Tone.Offline` 中的调度同样走 `Transport`，但离线渲染是按记录的绝对时间点重放（`renderLog` 逐 step 调 `triggerStepData`），**不重放 swing 偏移**；因此导出的 WAV 中 jazz pattern 的时值偏「直」，与实时听到的 swing 有差异。这是已知限制，若要一致，需要把 swing 偏移写进日志（下一轮再做）。

## 4. 未改动的部分

- 四轨 + SAMPLE 轨、16 步、反拍 hi-hat、侧链、低频处理（bass 60Hz 高通 + kick 触发 duck）、build / slam、锁 A 小调、导入采样、离线 WAV 导出：全部沿用 v1，没有回归改动。
- 键盘 `Space / 1–4 / B / S / Z X C V N / R` 全部保留；`1–4` 语义不变（Tech House 的 A–D），只是扩展到 `5–8`（E–H），并在 Deep / Jazz 包里映射到各自的 6 个 pattern。

## 5. 实测记录（无头 Chromium，`file://` 加载）

真跑过：

1. 加载无 console / page error；8 个 pattern 按钮、3 个风格按钮渲染正确。
2. 空格显示 `+`，`title` 有内容；点 BASS 空格生成 `A2`；`NOTE` 改 `C3` 后生成 `C3`。
3. 首次进入自动弹教程且只有 3 步（`queue: [0,1,2]`）；`Space` 起停 → 进第 2 步；BASS 空格 → 进第 3 步；按 `2` → 教程完成并关闭。
4. 教程打开、焦点在教程按钮上：`Space` 仍起停、`3` 仍切 pattern —— 键盘未被吃掉。
5. 课程菜单 8 项、已学项打 ✓；`跳過` 立即推进并关闭；`startLesson` 任意项可单独开课。
6. 检测条件：FILTER 拖动判定通过；`X` 静音 BASS 判定通过；未播放时按 `S` 不静默失败，提示「先按 Space」。
7. 风格切换：TECH 127 / 8 组 → DEEP 122 / 6 组 → JAZZ 124 + swing 0.35，品牌副标题同步；切回 TECH 后 BPM 与 8 组恢复。
8. 编辑互不串：在 TECH 的 BASS 第 6 格加音，切到 DEEP 再切回，改动仍在。
9. jazz 全部 chord 事件的和弦音都落在 A 小调音级（脚本校验 `bad: []`）。
10. 离线渲染三风格各 3 个 pattern（2 小节）：时长符合各自 BPM（tech 5.78s / deep 5.93s / jazz 5.87s 含 2s 尾），peak 0.63–0.75、RMS 0.05–0.08，均非静音，无报错。

未验证（只能由使用者判断）：

- 耳机上的实际听感：swing 0.35 是否够「爵士」、deep house 的 pad 是否过厚、8 组 pattern 之间的对比是否足够撑场。
- 教程在真实「零基础用户」手里的可发现性（本次修的是显而易见的缺陷，不是用户测试）。
- 真机 Firefox / Safari、20 分钟连续演奏的稳定性。
- jazz 的 swing 在导出 WAV 中缺失（见 3.4 末，已知限制）。
